# wp-radar Release-Pakete

ARM64-Vorabversionen für eHive One. Installation über den SmartHub-App-Store.

Voraussetzung: SmartHub mit der paketverwalteten Node.js-24-Laufzeit. Der Installer prüft Paketname, Version, Architektur und SHA-256 vor der Installation. Lokale Konfigurationen bleiben erhalten.

Solange keine stabile Version veröffentlicht ist, wählt der Installer die neueste Vorabversion. Ein bestimmter Release lässt sich mit `--tag` auswählen.
